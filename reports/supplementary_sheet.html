The problem. Given a document and a corpus of its genre, rank the kinds of statement the document lacks by how many of its 200 closest peers make them, and show the peers' own sentences as evidence. One engine, no genre-specific code: a genre is a pack of configuration and data. Two packs ship, privacy policies and cs.CL/cs.LG papers. Nothing is a verdict: every number is a count of peers, every quote is theirs.

Run it yourself · three commands

1

Install into a virtual environment (Python 3.11).

python3.11 -m venv .venv .venv/bin/pip install -e .
2

Run the tests. They need no data and no large model weights.

.venv/bin/python -m pytest -q # 491 passed
3

Build a pack in smoke mode on the 200-document corpus (README explains the data download).

python -m experiments.run \ --config configs/pack_privacy.yaml \ --overlay local --overlay smoke

What keeps the numbers honest

  • Every experiment runs through experiments/run.py with a config; each run records its config hash, git commit, device and the version and hash of every prompt it rendered.
  • The report's source carries no typed number: every value is filled by key from reports/tables/report_fragments/values.json, written by analysis/tables.py from the run outputs.
  • Tests assert that the committed report, tables and figures equal a fresh build, so the submitted text cannot drift from the results.
  • Smoke mode (200 documents per genre, small models) must pass before any full run; the fresh-clone test of 2026-10-25 is recorded in the changelog.
  • Negative findings are kept: the plan and changelog record what did not work and why, including the privacy-policy result above.

Using the demo

  • Start with a pinned example: the guided walkthrough narrates each step and ends with a challenge-and-reveal on a benchmark instance.
  • Paste or upload your own policy or paper; auto-detect picks the pack. On the free CPU a policy takes about 10 s and a paper about 36 s.
  • Click a ghost paragraph to open its evidence: peer count, five peer sentences with document ids, suggested wording.
  • The cohort panel re-ranks without re-embedding: change k, the category filter or the date window and watch the list move.
  • The About tab carries the same numbers as the report tables.
